# The AR4 robot arm (mk5): a description and its meshes' manifest

- `ar4.urdf`: the description of Annin Robotics' AR4 (mk5), generated by xacro from `annin_ar4_description` in
  `ar4_ros_driver`, kept byte for byte as it was read (an experiment pins it by sha256). Its kinematics and inertial
  values are MIT: `LICENSE` beside it is that repository's licence, with its copyright line.
- `visuals.json`: the manifest of its eighteen visual meshes (`mime.asset_manifest/1`): each file's sha256, size and
  git blob, at Annin Robotics' repository at a pinned commit. **No mesh is here, or anywhere MIME hosts.** The meshes
  are Annin Robotics' design files, under its non-commercial licence, which forbids redistributing them in any form,
  converted or decimated copies included, so each record's tier is `referenced`.

An experiment that reads `ar4.urdf` finds `visuals.json` beside it, and its stage names each mesh by the manifest's name
and the file's sha256. `mime visuals fetch examples/descriptions/ar4/` downloads each mesh from the pinned commit,
checks its sha256, and converts and decimates it on this machine into the asset cache, never into a saved or a run
folder. Without them the stage draws simple shapes from the description's frames.

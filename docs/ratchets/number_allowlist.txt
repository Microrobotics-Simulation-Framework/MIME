# Lines of a hand-written page source or a package README that carry a number token, each with its own reason (not
# the start list's, `present at D1-min`):
# `file  tokens  #k  # reason`, the tokens the line's number tokens in order and `#k` its occurrence index, the line's
# order among the lines of that file carrying the same tokens (computed, never stored). A wording edit keeps a line's
# entry; a changed, added, removed or swapped number is a new key, which fails until it has its own line, and so does a
# copy of a listed line (an unlisted #2). `mime docs check` fails on a line not listed here or in readme_numbers.txt,
# and on a listed key that matches no line (delete its line). It records a cut, so a line added needs its reason
# logged; a number a page needs is a claim record's, named by its id (see MIME-ANO-nnn).

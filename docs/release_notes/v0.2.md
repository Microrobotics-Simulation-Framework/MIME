# MIME v0.2 — release notes (preview)

> v0.2 is in preview. The user-facing API is settled and these notes are
> drafted ahead of the actual release. Items tracked as remaining work
> before the tag are listed at the end.

## Highlights

* **MADDENING v0.2 alignment** — every node migrated to MADDENING v0.2's
  `halo_width()` API and the `static_data` channel; the `maddening` pin is
  `>=0.2.1,<0.3` (the LBM sharding work needs v0.2.1).
* **Compile-time edge validation** — `GraphManager.compile()` flags
  shape / dtype / units mismatches across graph edges; MIME's experiment
  graphs are pinned clean.
* **Preempt-resilient parameter sweeps** —
  `mime.data.sweep_resume.ResumableSweep` is the new reusable facility;
  `scripts/run_confinement_sweep.py` is the worked example.
* **Multi-GPU LBM sharding (preview)** — `IBLBMFluidNode` declares the
  MADDENING v0.2.1 sharded-stencil contract; the single-device fallback
  ships, multi-device execution is a tracked follow-up.
* **Cloud providers + provider-agnostic launcher** — AWS / GCP job
  templates alongside RunPod, launched via `scripts/launch_job.py`.
* **Runner extensions** — Profiler commands and an opt-in binary stream
  format on the experiment runner's ZMQ REP socket.
* **TF32 precision** — full-precision matmuls forced in the LBM moment
  transforms and the FVM pressure solver (GPU TF32 was silently
  corrupting low-magnitude float32 physics).

## What changed

### Node API

* `requires_halo` (boolean property) is **removed** in favour of
  `halo_width()` (method returning `dict[int, int]`). v0.2 derives the
  old property for backward compatibility, but subclassing a node that
  still defines `requires_halo` emits a `FutureWarning`; v0.3 escalates
  this to a `MigrationError`. See [Node API migration](../architecture/node_api_migration.md).
* `static_data` is the new channel for **large non-evolving arrays**
  (meshes, BEM LU factors, MLP weights). It keeps them out of the state
  pytree and out of every checkpoint. See [Static data usage](../architecture/static_data_usage.md).
* **Shared fluid-node contract** — `FVMFluidNode`, `IBLBMFluidNode`,
  `StokesletFluidNode` and `DefectCorrectionFluidNode` are now
  graph-interchangeable for the single-immersed-body case
  (`drag_force` / `drag_torque` outputs, `body_*` inputs). The contract
  document lives at `src/mime/nodes/environment/FLUID_NODE_CONTRACT.md`.

### Compile-time edge validation

`GraphManager.compile()` runs `validate()`, which checks every edge's
shape, dtype and units against the target's `BoundaryInputSpec`.
Mismatches are emitted as `ShapeMismatchWarning` /
`DtypeMismatchWarning` / `UnitMismatchWarning`. MADDENING v0.2.1
escalates shape and dtype mismatches to a hard `EdgeValidationError`;
unit mismatches stay advisory. Build a complete `boundary_input_spec()`
on custom nodes. See [Edge validation](../architecture/edge_validation.md).

### Preempt / resume

* MADDENING v0.2's checkpoint API (`save_state_with_manifest` /
  `load_state_with_manifest`, integrity-verified by a manifest hash) is
  the foundation.
* `mime.data.sweep_resume.ResumableSweep` wraps it into a sweep facility:
  items finished in a prior run are skipped, each new item is
  checkpointed immediately, and a snapshot directory mirrors the state to
  durable storage so cloud-spot preemptions resume cleanly.
* `scripts/run_confinement_sweep.py` is the worked example. See
  [Preempt / resume](../preempt_resume.md).

### Runner — profiler + opt-in binary stream

The experiment runner (`mime.runner.server`) gains REP commands:

* `profile` / `profile_jax_{start,stop,status}` — return a Perfetto-format
  trace dict from MADDENING's profiler; `scripts/profile_experiment.py`
  is the thin client.
* `stream_info` / `set_stream_format` — the runner now publishes
  `ResultFrame`s as JSON by default; switching to compact
  `BinaryStateEncoder` frames is opt-in via `MIME_STREAM_FORMAT=binary`
  or `set_stream_format`, with `stream_info` as the handshake by which a
  consumer learns the active format and decode schema. The matching
  MICROROBOTICA C++ binary decoder is implemented on MICROROBOTICA's
  `feat/binary-resultframe-decoder` branch.

### Cloud — AWS / GCP

`scripts/launch_job.py` is the provider-agnostic launcher;
`jobs/production_h100_aws.yaml` and `jobs/production_h100_gcp.yaml` are
spot-enabled templates (safe to use now that `ResumableSweep` resumes
preempted sweeps). See [Launching cloud jobs](../infrastructure/cloud_launch.md).

### Multi-GPU LBM sharding — preview

`IBLBMFluidNode` declares the MADDENING v0.2.1 sharded-stencil API
surface — `state_fields` excludes the drag domain integrals,
`domain_integral_fields` declares them so `ShardedStencilNode`
`lax.psum`s them, `static_data` conditionally shards the pipe-wall masks
via a new `multigpu_shard_axis` constructor parameter, and
`update_padded` accepts the v0.2.1 `static_padded` / `shard_info` kwargs.

**Status (preview):** the single-device fallback works (delegates to
`update()` on the un-padded interior). Multi-device execution — per-slab
UMR mask recomputation against `umr_sdf` and halo-aware D3Q19 streaming
— is a tracked follow-up; `update_padded` raises a clearly-worded
`NotImplementedError` on a non-empty `shard_info` / `static_padded`.

### Numerical fixes

* **TF32** — GPU TF32 was silently corrupting low-magnitude float32
  matmuls (e.g. LBM momentum-moment near-cancellations). v0.2 forces full
  precision in the LBM moment transforms and the FVM pressure solver.
  Custom GPU code should use `precision="highest"` for precision-sensitive
  matmuls. See [GPU precision](../user_guide/gpu_precision.md).
* **LBM mass conservation** — fixed a BGK-collision rounding bias that
  drifted total density over long runs.

## Migrating from v0.1

A custom `SimulationNode` written against MIME v0.1 needs at minimum:

1. **Replace `requires_halo` with `halo_width()`.** Pointwise nodes drop
   the old property and inherit the `{}` default; stencil nodes return a
   per-axis halo dict. Before / after examples in
   [the migration guide](../architecture/node_api_migration.md).
2. **(Optional) Move large non-evolving arrays to `static_data`.** Wrap
   them in `StaticArray(value)` and override the `static_data` property
   on the node. See [Static data usage](../architecture/static_data_usage.md).
3. **Declare a complete `boundary_input_spec()`** — every input gets a
   concrete shape, dtype, and `expected_units` tag. Edge validation
   warns (and v0.2.1+ errors) on mismatches.
4. **Bump the `maddening` pin** to `>=0.2.1,<0.3` if you need the LBM
   sharding API or v0.2.1's `EdgeValidationError` escalation; the
   v0.2.0 baseline still works for most users.
5. **Run the suite** — MIME's tests pin the new behaviours; the slow
   lane covers the verification benchmarks.

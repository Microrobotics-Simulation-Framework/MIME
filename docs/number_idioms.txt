# The structural idioms the number rule exempts: digit forms that name a shape, not a result. `pattern  # reason`,
# each pattern exact (`3D` covers neither `4D` nor `3d`), its tokens removed from a line before the line is keyed, so
# a line with `6 x 6` and a measured number is keyed on the number alone. A pattern stands alone: inside a word or a
# number (`13D`, `3Dx`), or before a unit, a per cent sign or a decimal part (`6 x 6 mm`, `6 x 6.5`), it is no idiom,
# and those numbers are keyed. A count that is a result ("takes 2 iterations") is no idiom. This is a list the rule
# reads, not a ratchet: an idiom no file uses is no failure. It grows only by a logged decision, and its length is
# printed.

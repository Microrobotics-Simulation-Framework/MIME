# `mime.core`

**What every node imports.**

## What goes here

- **`MimeNode`**, the base class of MIME's nodes, on MADDENING's `SimulationNode`.
- **Node metadata.**
- **Quaternion helpers**, with a norm that is safe at zero rotation. The 0.2 version produced a NaN there.

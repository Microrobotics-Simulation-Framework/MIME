# `mime.viz`

**Recording and viewing.**

## What goes here

- **Recording**, as a time-sampled USD layer over the scene, so a run can be replayed in any USD viewer.
- **Viewports.**

## Boundaries

- With `scene`, the only importer of `pxr`.
- The desktop application, MICROROBOTICA, is a separate project. It adapts to MIME's interfaces, not the reverse.

## Status

Empty. It is ported when recording is first needed.

- **`mime.viz.display` shows the view and returns `None`; a replacement of a declaration taken from `Experiment.based_on` or provided by a block (`exp.use`) is recorded, not warned** (`mime.viz`, `mime.experiment`). `display` used to return the page, so a call inside an `if`, a loop or a function showed nothing and raised nothing, against IPython's `display(x)`. It now shows the view through IPython's display machinery wherever it is called (a call as a cell's last line shows it once) and returns `None`; where no IPython is running it is refused (`visuals.display-outside-ipython`), whose action names `mime.viz.web_page` and `mime visuals web`. Code that used its return value uses `mime.viz.web_page`, which takes the same arguments (`RunWritten.view()` still returns the `WebPage`). Separately, changing what a based-on experiment took, or what a block provides, is those APIs' intended use: such a replacement is in `plan().replaced` and the build report and raises no `UserWarning`, where it raised one each time and a notebook that printed `plan().replaced` showed every note twice. A replacement of a declaration the experiment made itself (a notebook cell run again with other content) still warns.

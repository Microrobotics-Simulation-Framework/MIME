- **Declared precision** (precision P1): `Experiment(..., precision="float32" | "float64")`, float64 when not stated. A build enables JAX's 64-bit types whatever the precision, and `mime.core.run_dtype()` reads the declared precision, not JAX's flag; a node keeps its build's precision for its step, its initial state and its parameter leaves. The lock's `x64` records the declared precision, and a load reads it back. An undeclared precision is refused (`run.precision`). Script A and the settling ball run float32 with 64-bit types enabled with no wide operation in their step, bit for bit as float32 without them. The dtype audit (`mime.testing._dtype_audit`) reports the wide operations of a float32 step, report-only.

- **Declared precision** (precision P1): `Experiment(..., precision="float32" | "float64")`. `mime.core.run_dtype()` reads the declared precision, not JAX's flag; a node keeps its build's precision for its step, its initial state and its parameter leaves. A precision MIME does not run in is refused (`run.precision`), and a float32 JAX array handed to a float64 run is refused (`run.precision-lossy`: computed before the build enabled 64-bit types, it would enter rounded; pass Python or NumPy floats). Script A and the settling ball run float32 with 64-bit types enabled with no wide operation in their step, bit for bit as float32 without them. The dtype audit (`mime.testing._dtype_audit`) reports the wide operations of a float32 step, report-only.

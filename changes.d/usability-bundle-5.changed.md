- **Usability bundle 5: messages that name the problem once and blame the right party.** A body whose part was refused (a
  solid's radius below zero) is one problem: what follows from it (the body's derived mass, a drag's need of its hull)
  is no longer refused apart, and the part's refusal says so. A run of zero steps, a negative one or one under a step
  is named as such (`run.duration`), and its "do:" offers one run, not the same one twice. A reason that is only a
  placeholder word (`"pending"`, `"TODO"`, `"TBD"`, `"FIXME"`) is refused with "did you mean `pending()`". An entry's
  or a namespace's version must be a version (numbers joined by dots, PEP 440; `"banana"` stops registering) and
  versions list in that order (`0.9.0` before `0.10.0`). `run()`'s docstring and the README say that a run continues the
  last one. A check of the built graph that faults a node a lab's entry built (`maddening.shape`, `maddening.dtype`,
  `maddening.units`, `maddening.error`, `post-build.units`, `post-build.input-units`, `post-build.unsaved-arguments`,
  `run.run-constant`) is no longer worded "MIME defect: report it with this build report": it names the entry and its
  package, says what its author changes, and the footer says it is not MIME's defect; the same check of MIME's own
  entries is still MIME's.
